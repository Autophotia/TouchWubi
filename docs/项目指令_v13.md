## 5. 网络代理规则（AI 自动启动，用完即关）

1. 脚本在 `D:\Program Files\CentBrowser\`，18 个 .cmd = 9 栈 ×（主+备用）。**AI 绕过交互式 .cmd，直接操作底层**（实测可行）：
   - 启动：`cd "/d/Program Files/CentBrowser/Xray" && ./xray.exe -c config.json`（后台运行）；无窗口用 `wscript xray_no_window.vbs`。
   - 入口固定：socks `127.0.0.1:1080`、http `127.0.0.1:1081`。
   - 节点信息读 `Xray\config.json` 的 `outbounds[0].settings.vnext[0]`（address:port），不必读窗口输出。
2. 九栈实测（验证统一 `git ls-remote`）：clash✓(7890,sslVerify=false)、Xray✓(1080)、hysteria✓(1080)、singbox✓(1080)、hysteria2✓(1080,IPv6)、juicity✓(1080)、mieru✓(3080,须 ip_2)、shadowquic✓(4080)、naiveproxy✗(崩溃,不可用)。1080 六栈共用同时只能一个。
3. **AI 自动启动代理标准流程**（无需用户手动，用完即关）：
   ① 查进程：`netstat -ano | grep ":1080 "` 有 LISTENING 即已启动，跳过。
   ② 未启动则后台启动：`cd Xray && ./xray.exe -c config.json`（run_in_background）。
   ③ 验证：`netstat -ano | grep ":1080 "` 有 LISTENING + `tasklist | grep -i xray` 有进程。
   ④ 读节点：config.json outbounds 的 address:port。
   ⑤ 连网验证：`git ls-remote` 返回 commit hash。
   ⑥ 执行 git push。
   ⑦ 若 ls-remote 失败（节点死）：更新订阅——跑 `Xray\ip_Update\ip_1.bat`（wget 拉 gitlab 订阅写 config.json），再重启 xray。**更新订阅是「节点失效」时的兜底，非每次必做**。
   ⑧ **用完即关**：git 操作全部完成后 `taskkill //F //IM xray.exe` 停代理（Git Bash 里 `/F` `/IM` 会被转成路径，必须用双斜杠 `//`），验证 `netstat -ano | grep ":1080 "` 已无 LISTENING，不留常驻进程。
4. 「窗口即生命线」只适用于**交互式 .cmd 启动**（代理挂在 cmd 窗口，关窗即消失）；AI 用后台方式（run_in_background / wscript 无窗口）启动则不受此限。
5. 验证网络用 `git ls-remote`，勿用 Git Bash 自带 curl（MSYS2 curl 经代理 HTTPS 失败属其自身问题）。

## 7. 资料上云与协作分工（方案 C）

1. **双云各司其职**：git = 版本库（管演进，有版本历史/diff/合并/评审）；腾讯云 tdrive = 共享文件系统（管分发，上传即覆盖无版本历史）。
2. **设计基线统一进 git `docs/`**：BASELINE.md + 设计文档 + 项目指令。同账号不同电脑靠 `git pull` 拿最新；成员靠 git 协作（push/PR）。**旧约定「BASELINE 不进 git」已废止**。
3. **产物分发走 tdrive**：release zip、补丁 zip、报告放 `/02-产物/`；资料 `/01-资料/`、笔记 `/03-笔记/`。
4. **临时讨论/想法走项目动态 + 任务**，不落文件。
5. **项目记忆 `.workbuddy/memory` 保持本地**：不上云（agent 工作日志，非协作资料）。
6. **成员两条路径**：会 git 的给 push 权限在 docs/ 协作；不会 git 的（产品/测试）在动态/任务提想法由维护者落 git，定稿传可读副本到 tdrive 供浏览，**权威始终在 git**。
7. 权威层级：git docs/ > tdrive 副本 > 项目记忆。
8. **产物自动整理、上传前确认（2026-10-24 补）**：任务完成即自动整理——产物归位到本地规范目录（releases/、patchs/）、设计类进 git docs/ 并 push（**全自动上云**）；**tdrive 上传受系统强制规则约束**（任何上传/修改必须先经用户确认，不可绕过），故上传 tdrive 保持半自动：AI 自动整理 + 生成待传清单，**一次提示用户确认后批量上传**。git 是唯一全自动上云通道。
