## 七、以后遇到问题时怎么用这份基线

1. 先对照 §二 锚点：判断是「新回归」还是「历史漂移」，避免把登记项误当故障追。
2. 动手改 lua 前读交接文档 §三（三条铁律 + 显示/上屏分离机制 + 末尾空行硬规则）。
3. 若涉及「最新版 XX」，须跨三处检索（会话产物目录 / 另一台设备 / tdrive），
   `dev/docs/` 落盘不保证最新。
4. 智能联想仅移动端（`is_mobile` 门控）；PC 上屏后带 `^` 的联想窗口是小狼毫软光标，无害。
5. 部署三件事：覆盖 + 重新部署 → 切换一次方案 → 改过主题删 `themes/<t>/build/`。
